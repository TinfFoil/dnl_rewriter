# DNL Rewriter

This repository contains data and code related to our paper ["Fine-Tuning vs Prompting Techniques for Gender-Fair Rewriting of Machine Translations"](https://aclanthology.org/2025.gebnlp-1.28/), published at the 6th Workshop on Gender Bias in NLP at ACL 2025. 

## Data
* The `data` folder contains the manual DNL reformulations that we added to the original gendered translations from [MT-GenEval](https://huggingface.co/datasets/gsarti/mt_geneval) and [mGeNTE](https://huggingface.co/datasets/FBK-MT/mGeNTE). 
* The `dataset` folder contains our dataset, split into training and test splits. 
* The `adapted_neogate` folder contains a version of [Neo-GATE](https://huggingface.co/datasets/FBK-MT/Neo-GATE) adapted to our DNL grammar (as defined in `schwa_template.json`); `neomorphemes.txt` is needed to run the evaluation. 

## Code
The `scripts` we share are used for the following purposes:
* `create_my_dataset.py` creates a copy of our training dataset, loading the external datasets and our files from the `data` folder, and saves it to the `dataset` folder
* `finetune_rewriter.py` fine-tunes a model on our task using our training dataset
* `generate_predictions.py` collects raw outputs on the evaluation dataset from a fine-tuned model
* `prompt_rewriter.py` prompts a model to perform our task and collects its raw outputs on the evaluation dataset; prompts are created following our templates (described in the paper) and using examples from our training dataset when in a few-shot setting

## Results
The `experiments` folder contains the following for each of the experiments we carried out:
* post-processed (cleaned) model predictions that can be evaluated directly
* detailed reports generated by [Neo-GATE](https://huggingface.co/datasets/FBK-MT/Neo-GATE) as part of the evaluation
